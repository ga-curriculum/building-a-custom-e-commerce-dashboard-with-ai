# 🧑‍🏫 Facilitator Guide: Module 6 – Building a Custom E-commerce Dashboard with AI

## ⏱️ Duration
**60 minutes total**

---

## 🎯 Job To Be Done
Help engineers working with UI frameworks accelerate feature delivery by integrating AI-assisted tools into their development workflow for measurable productivity gains.

---

## 🎯 Learning Objectives
By the end of this module, learners will:
✅ Rapidly prototype complex, reusable UI components with AI-assisted tools.
✅ Integrate data visualization and dashboard features using AI-driven workflows.
✅ Document standards and reflect on how AI reduced development time.
✅ Practice few-shot prompting to extend project functionality.

---

## 🗺️ Content Flow

> **Note:** Students will start their DEVELOPMENT_RULES.md files in this module, and will continue to adjust, edit, and add to them throughout the rest of the day as they learn and build.

### 1. **Kickoff & Demo (10 min)**
- Demo: Using **GitHub Copilot/Cursor** to scaffold a dashboard (e.g., sales metrics, order management, customer insights) **using the tech stack set up in Module 5 (Next.js, Shadcn/UI, Supabase, etc.)**.
- Show how to leverage **Shadcn/UI** docs and Copilot/Cursor chat for generating components.
- Highlight importance of documenting as you build (CLAUDE.md snippets).

---

### 2. **Hands-On Build: Dashboard Prototyping (30 min)**
- Learners:
  1. Clone a starter repo or scaffold a project **with the AI-ready stack from Module 5**.
  2. Build three reusable React components (sales metrics card, order table, customer insights chart).
  3. Integrate at least one data visualization (chart or graph) with AI help.
  4. Use AI to explain or document how they fixed at least one issue encountered.
  5. Practice few-shot prompting: Add a new feature or CRUD endpoint, using Copilot/Cursor.

---

### 3. **Live Retrospective & Group Discussion (10 min)**
- Each learner shares a challenge that AI helped them overcome.
- Discuss documentation: How did you capture standards or fixes in CLAUDE.md?
- Group identifies best practices for future dashboard projects.

---

### 4. **(Stretch/Optional) Multi-Feature Extension (10 min)**
- For fast groups: Add multi-select, multi-delete, or "add to cart" features.
- Prompt: Use AI to suggest/refine implementation and update documentation accordingly.
