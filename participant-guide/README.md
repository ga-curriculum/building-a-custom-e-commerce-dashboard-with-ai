# 📄 Participant Handout: Module 6 – Building a Custom E-commerce Dashboard with AI

---

## 🎯 Learning Objectives
By the end of this module, you will:
✅ Use AI-assisted tools to build reusable UI components and dashboards.
✅ Leverage Copilot/Cursor and Shadcn/UI docs for rapid prototyping.
✅ Practice documenting your process and standards.
✅ Experiment with few-shot prompting to extend your app.

---

## 🏗️ Activity Steps

> **Note:** You will start your DEVELOPMENT_RULES.md file in this module, and you’ll keep updating and adding to it throughout the rest of the day as you learn and build.

### 1. **Get Started (10 min)**
- Clone the starter repo (or scaffold a project if instructed) using the tech stack you set up in Module 5 (Next.js, Shadcn/UI, Supabase, etc.).
- Install all dependencies (Next.js, Shadcn/UI, Copilot/Cursor).

---

### 2. **Build Your Dashboard (30 min)**
- Use Copilot or Cursor to:
  - Create three React components for your dashboard (suggested: Sales Metrics Card, Order Table, Customer Insights Chart).
  - Integrate a data visualization (e.g., chart for sales or customer trends).
- When you hit a bug or get stuck, use AI chat to explain and solve it.
- **Document** in your repo:
  - What AI prompt/feature helped you most?
  - One new rule or standard you’d add to your CLAUDE.md after this session.

---

### 3. **Extend with Few-Shot Prompting (10 min)**
- Use Copilot/Cursor to add a new feature (CRUD endpoint, button, or dashboard enhancement).
- Try a “few-shot” approach: Give the AI a couple of good examples to guide the output.
- Document how the AI helped and what you’d do differently next time.

---

### 4. **Share & Reflect (10 min)**
- Be ready to share:
  - A feature you built *faster* with AI.
  - One thing you added to your documentation.
- Reflection:
  - How did AI change your approach to building UIs?
  - What would you ask AI to improve or refactor if you had more time?

---

## 📌 Why This Matters
Building with AI means you can spend more time on what matters—business problems, not boilerplate. By documenting as you go, you’re future-proofing your work for both people and AI partners.

---

### **Reflection Questions**
- Which AI prompt saved you the most time?
- What rule or tip will you add to your CLAUDE.md?
- Where else in your workflow would you use AI next?

---

## ✅ **Checklist for Success**
- [ ] Three dashboard components built and tested
- [ ] One data visualization integrated
- [ ] Documented at least one new standard/rule in CLAUDE.md
- [ ] Used few-shot prompting to add/extend a feature
- [ ] Ready to explain how AI improved your process
